# DIGITAL ZERØ Autonomous Software Engineering Factory v3

## Flow
Detect → Analyze → Parallelize → Implement → Test → Security → Benchmark → PR → Human Gate → Deploy → Observe.

## Worktree Variants
- minimal
- maintainable
- performance

## Evidence Gate
A candidate is ineligible if required tests fail, critical security findings are introduced, or public API compatibility breaks outside explicit migration scope.

## Safety
Automatic merge is disabled by design. High-risk production changes remain approval-gated.
